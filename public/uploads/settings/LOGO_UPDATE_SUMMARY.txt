┌────────────────────────────────────────────────────────────────────┐
│ HOW TO UPDATE LOGO & NAME                                          │
├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│ Step 1: Access Settings                                            │
│   → Log in as Admin                                                │
│   → Click "Settings" in sidebar (gear icon)                       │
│                                                                    │
│ Step 2: Upload Logo                                                │
│   → Go to "Logo & Favicon" tab                                     │
│   → Click "Choose File" under "Hotel Logo"                        │
│   → Select image (PNG, JPEG, max 2MB, square recommended)         │
│                                                                    │
│ Step 3: Update Hotel Name                                          │
│   → Go to "General Settings" tab                                   │
│   → Update "Hotel Name" field                                      │
│   → Example: "Grand Hotel", "Luxury Resort", etc.                 │
│                                                                    │
│ Step 4: Save                                                       │
│   → Scroll to bottom                                               │
│   → Click "Save Settings" button                                   │
│   → Changes apply immediately across ALL portals!                  │
│                                                                    │
