How It Works

❌ Before (Broken)

body[data-khmer-font] * {
  font-family: 'Hanuman';
}

Problem: Applies to ALL elements including icons, breaking Font Awesome

✅ After (Fixed)

body[data-khmer-font] span:not([class*="fa"]) {
  font-family: 'Hanuman';
}

i[class*="fa-"] {
  font-family: "Font Awesome 6 Free";
}

Solution: Selectively targets text elements, excludes Font Awesome icons
