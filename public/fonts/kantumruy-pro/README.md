# Kantumruy Pro Font

Download Kantumruy Pro font from Google Fonts and place the following files here:

- KantumruyPro-Thin.ttf
- KantumruyPro-ExtraLight.ttf
- KantumruyPro-Light.ttf
- KantumruyPro-Regular.ttf
- KantumruyPro-Medium.ttf
- KantumruyPro-SemiBold.ttf
- KantumruyPro-Bold.ttf

## Download Link:
https://fonts.google.com/specimen/Kantumruy+Pro

## How to get the font files:
1. Visit the Google Fonts link above
2. Click "Get font" or "Download family"
3. Extract the zip file
4. Copy all .ttf files to this directory
