┌────────────────────────────────────────────────────────────────────┐
│ HOW IT WORKS                                                       │
├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│ The CSS uses SELECTIVE TARGETING to ensure:                       │
│   ✓ Font Awesome applies to icon elements (<i>)                   │
│   ✓ Khmer fonts apply to text elements (p, h1, label, etc.)       │
│   ✓ No conflicts between the two systems                          │
│                                                                    │
│ CSS Strategy:                                                      │
│   body[data-khmer-font] span:not([class*="fa"])                   │
│                          ^^^^^^^^^^^^^^^^^^^^^^^^                  │
│                          Excludes Font Awesome                     │
│                                                                    │

┌────────────────────────────────────────────────────────────────────┐
│ CONFIGURATION                                                      │
├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│ To enable Khmer fonts:                                             │
│   1. Go to: Settings > General Settings                           │
│   2. Select: Khmer Font Selection dropdown                        │
│   3. Choose: Hanuman or Kantumruy Pro                             │
│   4. Click: Save Changes                                           │
│                                                                    │
│ The font will auto-apply when:                                     │
│   • User locale is 'km' (Khmer)                                    │
│   • Font setting is not empty                                     │
│                                                                    │
│ Database:                                                          │
│   Table: settings                                                  │
│   Key: khmer_font                                                  │
│   Values: null, 'hanuman', 'kantumruy'                             │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                    │
├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│ Icons not showing?                                                 │
│   → Clear cache: php artisan cache:clear                          │
│   → Check browser console for CSS errors                          │
│   → Verify Font Awesome CSS loaded in page source                 │
│                                                                    │
│ Khmer font not applying?                                           │
│   → Check locale: app()->getLocale() should be 'km'               │
│   → Verify setting exists in database                             │
│   → Check body has data-khmer-font attribute                      │
│                                                                    │
│ Icons broken after font change?                                    │
│   → This shouldn't happen! The CSS excludes icons                 │
│   → Check khmer-fonts.css has :not([class*="fa"]) exclusions      │
│   → Verify Font Awesome protection rules present                  │
