# Hanuman Font

Download Hanuman font from Google Fonts and place the following files here:

- Hanuman-Thin.ttf
- Hanuman-Light.ttf
- Hanuman-Regular.ttf
- Hanuman-Bold.ttf
- Hanuman-Black.ttf

## Download Link:
https://fonts.google.com/specimen/Hanuman

## How to get the font files:
1. Visit the Google Fonts link above
2. Click "Get font" or "Download family"
3. Extract the zip file
4. Copy all .ttf files to this directory
